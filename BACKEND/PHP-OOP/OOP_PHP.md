Apa itu Object Oriented Programming ?
Object Oriented Programming adalah sudut pandang bahasa pemrograman yang berkonsep "objek"
ada banyak sudut pandang bhs pemograman, tapi OOP sngat populer saat ini dan perlu di mengerti
OOP yaitu: Objec dan Class

apa itu object ?
object adalah data yang berisi field / properties / attributes dan method / function / behanvio

Apa itu Class ?
class adalah blueprint prototye atau cetakan untuk membuat object
class berisikan deklarasi semua properties dan function yang dimiliki oleh object
